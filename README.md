# 📝 Todo App

A beautiful, fully-featured Todo application built with vanilla JavaScript, HTML, and CSS. Manage your daily tasks with a modern UI featuring animations, filters, and persistent local storage.

## 🚀 Quick Start

1. **Download the file**  
   Get `todo.html` from this repository

2. **Open in browser**  
   Simply double-click the file

##### Or Use the version that deployed in netlify: https://silly-wisp-d5f5c4.netlify.app/
